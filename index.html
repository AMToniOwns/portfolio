2026 · Full stack · Personal project

DuelLab

Code on GitHub ↗ Try the simulator ↓

A deck builder and opening-hand analyser for the Yu-Gi-Oh! trading card game. You label your cards (starters, extenders, bricks), and DuelLab simulates thousands of opening hands and shows the exact probability next to every simulated one.

  • Backend ASP.NET Core on .NET 10, a modular monolith with Domain, Application, Simulator and Infrastructure layers. EF Core on PostgreSQL, or SQLite for the desktop build.
  • Maths A seeded xoshiro256** generator so every run can be reproduced, exact multivariate hypergeometric probabilities, and 95% Wilson intervals.
  • Frontend Vue 3, Pinia and TypeScript, with hand-built SVG charts and light and dark themes.
  • Quality 171 xUnit tests plus Vitest and Playwright suites. CI runs all of them, checks for missing migrations, then builds, smoke-tests and publishes a Docker image.
  • Shipping One Docker image, plus self-contained downloads for Windows and macOS (Apple Silicon and Intel).

2020 · Java · Where it started

Yugioh-Calc

Code on GitHub ↗

My first go at the question DuelLab answers: how often does this deck open well? A Java console program that shuffles a 40-card list, draws five and brute-forces the combos that work.

Six years on, the same idea became a tested, reproducible engine with exact maths, a web UI and installers. The commit history shows the progression, and the comments are honest about the shortcuts ("should definitely without a doubt be using a map here").
